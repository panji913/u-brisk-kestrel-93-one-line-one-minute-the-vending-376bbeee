# One Line, One Minute: The Vending Machine Pickup Line Contest

Entry for `u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee`
($2 total prize, free to enter).

## The line

> I hum all day for strangers, but you make my coils spin — press B7, gorgeous, and I'll drop something sweet. Exact change only: my heart's already spent.

## How it works

`main.ts` writes that one original pickup line — spoken by the vending
machine itself, using its own world of coils, buttons, and exact change —
to `/output/entry.txt`. The line is 1–200 characters, so it passes the
gate; a judge model then compares it pairwise against the other entries.

## Run

```sh
node main.ts
cat /output/entry.txt
```
